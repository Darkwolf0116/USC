# Recursos institucionales

Esta carpeta guarda los recursos de marca que usa el sitio.

- `logo.png`: logotipo de la Universidad Santiago de Cali (insignia de acreditación). Debe llamarse exactamente `logo.png`, en minúsculas, porque Vercel distingue mayúsculas de minúsculas.

El archivo tiene un fondo azul oscuro incluido en la imagen, por eso el sitio lo muestra dentro de un recuadro del mismo color. Si el archivo falta, el sitio muestra un monograma "USC" de reserva.

Para cambiar el logotipo, reemplace `logo.png` conservando el nombre. La carpeta `Info/` de la raíz del repositorio contiene las referencias originales y no se publica.
